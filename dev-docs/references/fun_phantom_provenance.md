# Fun / demo phantom provenance

This file records the source, license, retrieval date, locked ingest transform, and any repair or
validation exceptions for the **demo / non-clinical** phantoms shipped from
[`../plans/DEMO_PHANTOMS_CLOTHED_AND_STEAMBOAT_PLAN.md`](../plans/DEMO_PHANTOMS_CLOTHED_AND_STEAMBOAT_PLAN.md).

These meshes are labeled **(demo)** in the GUI/docs and must **never** be presented as dosimetry
reference phantoms. Mesh-asset licenses are tracked here (and in `phantom_data/NOTICE_*.txt` for
CC BY / CC BY-SA assets) — **not** in `dev-docs/THIRD_PARTY_NOTICES.md`, which is the Python-package
inventory only.

Ingest pipeline (shared): `scripts/phantom_gen/ingest_fun_mesh.py` reads the per-mesh locked
transform from `scripts/phantom_gen/fun_mesh_manifest.json`, applies
`raw → Euler rotate → uniform scale to height_cm → fill/cap → PSD anchor (obj_y_up=False,
meters_to_cm_if_small=False, explicit flip) → re-fix winding/normals → quadric decimate` and validates
with `validate_phantom.py --require-trimesh` (watertight `True`, ≤20k faces, face-up gate,
outward-normal ray gate). The reduced preview is generated by `generate_reduced.py` (real quadric
decimation; never `--allow-subsample`).

## Cosmic Buddha (`cosmic_buddha`)

- **Object:** "Buddha draped in robes portraying the Realms of Existence" (Cosmic Buddha), Chinese,
  Northern Qi–Sui dynasty. Freer Gallery of Art, Smithsonian Institution.
- **License:** **CC0** (Creative Commons Zero, Public Domain Dedication). SI credit is *encouraged
  but not required*; no `NOTICE_*.txt` sidecar is needed under CC0.
- **Source (retrieved 2026-07-22):**
  - Mesh file (used): Wikimedia Commons —
    `File:Cosmic-buddha-laser-scan-150k (Smithsonian Institution).stl`
    (`https://commons.wikimedia.org/wiki/File:Cosmic-buddha-laser-scan-150k_(Smithsonian_Institution).stl`).
    This is the ~7.5 MB, ~150k-face manageable mirror — deliberately **not** the 2.88 GB
    full-resolution scan.
  - Smithsonian 3D object page:
    `https://3d.si.edu/object/3d/buddha-draped-robes-portraying-realms-existence:d8c62be8-4ebc-11ea-b77f-2e728ce88125`.
  - License verified via the Commons API `imageinfo.extmetadata` on 2026-07-22: `LicenseShortName=CC0`,
    `UsageTerms="Creative Commons Zero, Public Domain Dedication"`, `Artist=Smithsonian Institution`.
  - Downloaded source integrity: Commons SHA-1 `0fe6ca26e9212eafd4d47884af9ca671ef354a2d` (7,500,084 bytes),
    confirmed on download.
- **Geometry limitation:** The statue is a **standing draped figure that is missing its head and
  hands** (broken off in antiquity). Expect a shorter effective height for a "human" mesh, a weaker
  "face" cue for the face-up check, and odd GUI habitus labels. It remains a valid draped full-body
  demo because the anterior-beam smoke and all validate gates pass.

### Locked ingest transform (discovered + locked 2026-07-22)

Orientation was discovered from the raw mesh via extent inspection and orthographic / depth-map
renders (side, top, and per-face depth maps), then locked in `fun_mesh_manifest.json`:

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| `rotate_deg` | `[0, 0, 0]` | Raw axes already map to the PSD frame: raw **Z** = superior–inferior with the crown/top at `max Z`; raw **X** = lateral; raw **Y** = anterior–posterior. No rotation needed. |
| `height_axis` | `z` | Longest raw span (raw Z span ≈ 1514.7 mm → scaled to 151 cm). |
| `height_cm` | `151.0` | Preserves the true (headless) statue scale (`scale ≈ 0.0997`). |
| `flip_y` | `false` | The carved "realms" relief, arm/hand stubs, and scalloped robe hem are on the raw **−Y** face (anterior); the smooth back is **+Y** (posterior). `flip_y=false` anchors the posterior back to the table (`y_max ≈ 0`) with the anterior toward **−Y**. |
| `target_faces` | `6000` | Shipping budget (3k–8k); `_reduced_1000t` preview also shipped. |
| `face_up_frac` | `0.55` | Default face-up threshold (passed comfortably). |
| `face_up_band_frac` | **`0.20`** | **Headless exception:** because there is no head, the face-up gate is applied to the superior **20%** robe/torso band (vs the default 12%). |

### Repair / watertight

- **No hole-fill or Blender cap was required.** The raw 150k-face mesh is already watertight
  (`trimesh.is_watertight = True`, `euler_number = 2`), and the shipped decimated mesh validates
  `watertight is True`.

### Validation + smoke results (2026-07-22)

- `validate_phantom.py --require-trimesh --face-up-frac 0.55 --face-up-band-frac 0.20`: **PASS** —
  `face_count = 6000` (≤20k), anchors OK (`x_mid≈0.03`, `y_max≈-0.02`, `z_max≈-0.05`),
  `height_z ≈ 150.9 cm`, `watertight = True`, face-up `PASS`
  (`y_min_headband ≈ -23.4 ≤ threshold ≈ -17.3`), outward normals `200/200` (fraction 1.0),
  Phantom load OK (18,000 cells).
- **Anterior-beam smoke** — `mode=calculate_dose`, `phantom.model=human`,
  `phantom.human_mesh=cosmic_buddha`, against the package example
  `src/mypyskindose/example_data/RDSR/siemens_axiom_example_procedure.dcm`:
  PSD ≈ **16.28 mGy**; the top-30 dose cells are **all** on the anterior (**−Y**) side
  (30 negative / 0 positive, mean Y ≈ −12.3 cm; dose-weighted mean Y ≈ −9.6 cm). Entrance is on the
  anterior side, as required.
- **`plot_setup` smoke:** phantom builds and positions on the table without error.
