Bundled icon font for the GUISkinDose GUI (replaces the former remote
`<link>` to fonts.googleapis.com so the app makes no third-party requests).

Attribution (required by Apache 2.0 §4): this file notes the font name,
copyright owner, and license above; a full copy of the license ships beside
the font in LICENSE-APACHE-2.0.txt (§4(a)).
No changes to the font bytes were made. The vendored stylesheet is the
upstream css2 output with only the `src` URL localized, plus one deliberate
alignment: the `.material-symbols-outlined` class declares `font-weight: 300`
to match the `@font-face` (upstream ships `normal` there, which resolves to
the same single face, but the explicit match leaves no browser guessing).
